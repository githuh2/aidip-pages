많은 기업이 특허를 등록하고 서랍에 넣어둡니다. 하지만 특허 한 건으로 벤처인증을 받고, 인증으로 정부지원사업에 지원하고, 그 실적으로 투자 유치까지 연결됩니다.

IP를 사업 전략의 일부로 설계하면, 등록비용은 투자가 됩니다.

CASE STUDY

스타트업 A사는 특허 2건으로 벤처인증을 받고, 기술보증기금에서 5억 원 보증을 확보했습니다. 같은 특허로 TIPS 프로그램에도 선정되어 R&D 자금을 추가 확보했습니다.

01

기업인증 지원

벤처인증, 이노비즈, 메인비즈를 IP로 해결합니다.

특허·실용신안 등 지식재산권을 활용한 기업인증 취득을 지원합니다. 인증 요건에 맞는 IP 포트폴리오를 설계하고, 신청 절차를 안내합니다.

이런 분이 필요합니다.
  • 벤처인증을 받고 싶은데 IP 실적이 부족한 기업
  • 기업인증으로 세제 혜택을 받고 싶은 기업
  • 정부지원사업 지원 자격을 확보해야 하는 기업
02

IP 기반 자금조달

특허가 담보가 됩니다.

기술보증기금, 신용보증기금 등을 활용한 IP 담보 대출 및 보증을 지원합니다. 특허 가치평가부터 보증서 발급까지 안내합니다.

03

정부지원사업 IP 전략

TIPS, 창업사업화, R&D 과제의 IP 요건을 충족합니다.

정부지원사업 신청 시 필요한 IP 실적 확보, 사업계획서의 IP 전략 수립, 과제 수행 중 발생하는 직무발명 관리까지 지원합니다.

절차 안내

IP 활용 전략 수립부터 실행까지.

벤처인증 — 특허 등 IP 보유 시 '혁신성장 유형'으로 신청 가능. 세제 감면, 입찰 가산점 등 다양한 혜택이 있습니다.
